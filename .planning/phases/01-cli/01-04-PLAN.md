# Plan 01-04: 規則管理命令

**Phase:** 01-cli
**Created:** 2026-03-19
**Status:** Not started
**Dependencies:** Plan 01-02 (倉庫管理命令)

## Objective

實作 `rules` 命令，讓使用者可以管理 ACR 構建規則，包括清理已合併分支的規則。

## Requirements Covered

- CLRU-01: 使用者可執行 `asor rules <alias>` 列出構建規則
- CLRU-02: 使用者可執行 `asor rules <alias> add <branch>:<tag>` 新增規則
- CLRU-03: 使用者可執行 `asor rules <alias> remove <rule-id>` 刪除規則
- CLRU-04: 使用者可執行 `asor rules <alias> cleanup` 清理已合併分支規則

## Tasks

### 1. Rule Manager Service
- [ ] 建立 `src/services/rule-manager.ts`
- [ ] 實作 `listRules(alias: string)` 方法：
  - 查詢本地資料庫
  - 呼叫 ACR API 取得規則列表
  - 同步本地資料庫
- [ ] 實作 `addRule(alias, branch, tag)` 方法：
  - 檢查規則數量限制（10 條）

  - 刪除對應規則

## CLI Interface

```bash
# 列出規則
asor rules my-app
# 輸出:
# Rule ID  Branch Pattern  Tag Template  Status
# 1        main           latest        active
# 2        develop        dev           active
# 3        feature/*      feature-*     active

# 新增規則
asor rules my-app add feature/auth:auth
# 輸出: ✓ Rule created: feature/auth -> auth

# 刪除規則
asor rules my-app remove 3
# 輸出: ✓ Rule removed: feature/* -> feature-*

# 清理已合併分支規則
asor rules my-app cleanup
# 輸出:
# Checking branch status...
# ⚠ Found 2 rules for merged branches:
#   - feature/login -> feature-login (merged)
#   - feature/auth -> auth (merged)
# Remove these rules? [y/N] y
# ✓ 2 rules removed

# 預覽清理（不實際刪除）
asor rules my-app cleanup --dry-run
# 輸出:
# Would remove 2 rules:
#   - feature/login -> feature-login
#   - feature/auth -> auth

# 同步本地與 ACR
asor sync
# 輸出:
# Checking ACR repos...
# ⚠ Local repo 'old-app' not found in ACR
#   - [D]elete local entry
#   - [U]pdate ACR (create repo)
#   - [S]kip
# ✓ Sync complete: 2 repos updated
```
