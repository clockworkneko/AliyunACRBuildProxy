## CLI Interface

```bash
# 設定 GitHub token
asor config set github-token <pat>

# 設定阿里雲憑證
asor config set aliyun-access-key <ak>
asor config set aliyun-secret-key <sk>
asor config set aliyun-region cn-hongkong

# 查看設定
asor config get github-token
asor config list

# 驗證憑證
asor config validate
```
