## Objective

實作 `resolve` 命令，讓使用者可以透過別名查詢 ACR 映像路徑。

## Requirements Covered

- CLIQ-01: 使用者可執行 `asor resolve <alias>` 查詢 ACR 映像路徑
- CLIQ-02: 使用者可執行 `asor resolve <alias>:<tag>` 查詢特定標籤
- CLIQ-03: CLI 輸出完整 docker pull 命令
- CLIQ-04: 使用者可執行 `asor resolve <alias> --copy` 複製路徑到剪貼簿

## CLI Interface

```bash
# 基本解析
asor resolve nginx-latest
# 輸出: registry.cn-hongkong.aliyuncs.com/myorg/nginx:latest

# 指定 tag
asor resolve nginx-latest:alpine
# 輸出: registry.cn-hongkong.aliyuncs.com/myorg/nginx:alpine

# 複製到剪貼簿
asor resolve nginx-latest --copy
# 輸出: ✓ Copied to clipboard

# 輸出 docker 命令
asor resolve nginx-latest --docker
# 輸出: docker pull registry.cn-hongkong.aliyuncs.com/myorg/nginx:latest

# 詳細模式
asor resolve nginx-latest --verbose
# 輸出:
# Alias: nginx-latest
# GitHub: https://github.com/myorg/nginx
# ACR: registry.cn-hongkong.aliyuncs.com/myorg/nginx:latest
# Region: cn-hongkong
```
