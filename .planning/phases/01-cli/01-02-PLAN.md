# Plan 01-02: 倉庫管理命令

**Phase:** 01-cli
**Created:** 2026-03-19
**Status:** Not started
**Dependencies:** Plan 01-01 (CLI 框架與憑證管理)

## Objective

實作 `add`、`list`、`remove` 命令，讓使用者可以管理 ACR 倉庫映射。

## Requirements Covered

- CLIR-01: 使用者可執行 `asor add <github-url> --alias <name>` 掛載倉庫
- CLIR-02: CLI 自動在阿里雲 ACR 建立對應倉庫
- CLIR-03: CLI 自動配置預設構建規則（main -> latest）
- CLIR-04: CLI 顯示掛載結果（ACR URL、docker pull 命令）
- CLIR-05: 使用者可執行 `asor list` 列出所有已掛載倉庫
- CLIR-06: 使用者可執行 `asor remove <alias>` 移除倉庫映射

## Tasks

- [ ] 建立 `src/db/schema.ts` - Drizzle schema 定義
- [ ] 定義 `repos` 表：

- [ ] 定義 `rules` 表：

- [ ] SQLite 檔案位置：`.asor/asor.db`（專案目錄下）

### 2. Orchestrator Service
- [ ] 建立 `src/services/orchestrator.ts`
- [ ] 實作 `provisionRepo(input: ProvisionInput)` 方法：
  - 解析 GitHub URL 取得 owner/repo
  - 檢查本地資料庫是否已存在 alias
  - 呼叫 ACR API 建立 namespace（若不存在）
  - 呼叫 ACR API 建立 repo
  - 建立 `FROM <image>:<tag>` Dockerfile 並推送到 GitHub 分支
  - 建立 ACR 構建規則
  - 儲存映射到本地資料庫
- [ ] 實作錯誤處理和重試邏輯（3 次 + 指數退避）

### 3. Add 命令
- [ ] 建立 `src/cli/commands/add.ts`
- [ ] 實作 `asor add <image:tag> --alias <name>` 命令
- [ ] 參數解析：
  - `<image:tag>`: 來源映像（如 nginx:latest）
  - `--alias <name>`: 別名（選填，預設為 `<image>-<tag>`）
  - `--namespace <ns>`: ACR namespace（選填）
  - `--region <region>`: ACR 區域（選填，預設使用 config）
- [ ] 流程：
  - 解析 image:tag
  - 生成 alias（預設 `image-tag`）
  - 建立 GitHub repo（如果未設定）
  - 建立 `nginx-latest` 分支
  - 自動生成 Dockerfile
  - 建立 ACR repo 和構建規則
  - 顯示結果

### 4. List 命令
- [ ] 建立 `src/cli/commands/list.ts`
- [ ] 實作 `asor list` 命令

### 5. Remove 命令
- [ ] 建立 `src/cli/commands/remove.ts`

  - 確認刪除

## CLI Interface

```bash
# 新增倉庫
asor add nginx:latest --alias nginx-latest
asor add node:18 --alias node-18 --namespace myorg

# 列出倉庫
asor list
asor list --json

# 移除倉庫
asor remove nginx-latest
asor remove nginx-latest --keep-acr
asor remove nginx-latest --force
```
